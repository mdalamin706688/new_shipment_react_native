# New Shipment React Native App

A mobile-first React Native application for managing shipments, built with Expo.

## Features
- Mobile-first responsive design
- Shipment tracking and management
- Cross-platform support (iOS, Android, Web)

## Installation

```bash
npm install
```

## Running the App

### Web (Mobile View)
```bash
npm run web
```

### iOS
```bash
npm run ios
```

### Android
```bash
npm run android
```

## Tech Stack
- React Native
- Expo
- React Native SVG
